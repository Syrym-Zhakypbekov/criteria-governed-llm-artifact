# Criteria-governed LLM decisions — research artefact

Code, prompts, synthetic test inputs, analysis scripts and aggregate results for the manuscript
«Criteria-Governed Large Language Model Agents in a Production University Platform: A Design-Science Study of Explainable
Knowledge Extraction and Decision-Making» (submitted to MDPI *Machine Learning and Knowledge Extraction*).

This repository contains **only the parts needed to reproduce the study**. The production platform (Astra,
International Information Technology University, Almaty) is not published. No personal data is included.

## Contents
| Path | What |
|---|---|
| `src/decision-ledger.ts` | the criteria operator: certificates, hard veto, weighted aggregate, escalation gate, lifecycle, field-level diff |
| `src/jrd-extract.ts` | contract extraction prompt, normalisation and criteria (`jrdCriteria`) |
| `src/card-ocr.ts` | business-card extraction prompt, schema, provenance criteria (`cardCriteria`) |
| `experiments/contracts/` | planted-defect generator and runner (36 synthetic supplier documents), threshold and stability analysis, figures |
| `experiments/business_cards/` | 40 synthetic business-card images and runner |
| `experiments/ellipse/` | external benchmark on the public ELLIPSE corpus: three rubric configurations × 3 repeats, human-anchored calibration |
| `results/` | raw per-document outputs of every run (synthetic inputs only) |
| `figures/` | Figures 1–5 and the graphical abstract, regenerated by `experiments/contracts/figs.py` |

## Reproduce
- TypeScript runners import modules of the production code base (`@/lib/gemini`, `@/lib/decision-ledger`); to run them standalone, provide a `geminiText(prompt, opts)` function that calls any LLM and returns text.
- Python analysis (3.11+): `pip install numpy pandas scipy scikit-learn matplotlib`.
- ELLIPSE: download `ELLIPSE_Final_github_train.csv` and the raw rater file from https://github.com/scrosseye/ELLIPSE-Corpus, then
  `python experiments/ellipse/build_jobs.py train.csv jobs.json 120 3` → run → `python experiments/ellipse/analyse.py ...` and `calibrate.py`.
- Models: Gemini via Vertex AI (ids and parameters in the manuscript, Appendix A). Results of LLM calls are not exactly reproducible across model versions; all outputs used in the paper are stored in `results/` and `experiments/ellipse/`.
